# Modality overview: all models on every combination of main signals they can handle

Selected checkpoint (`finetune_best.pt`) of each run on the 193 full dev streams, without page numbers and without document boundaries; only the scan start and end are given. Each section is one combination of the main signals (S statistics, T text, I image): the other signals are masked as in the modality ablations (vectors and presence zero), and every model trained with at least these signals is listed. A model is named by its experiment, the signals it was trained with and its context window. Overlapping windows are merged as deployed in MetaKat, scaled to the window: overlap W/8 (64 at W512), regular tail, centre-weighted cubic logits with the ramp ending at 3/4 of the overlap and 3/16 of the overlap ignored at artificial window edges.

- **Page type**: the 3,758 curated dev pages. Precision, recall and F1 are support-weighted averages over the page types, as in the README's page type evaluation.
- **Side**: the 111,193 dev pages with a DB placement (left/right/single), weighted the same way.
- **Border**: the 1,786 true document starts; precision, recall and F1 of the predicted starts (threshold 0.5).

All values in %. Generated by `tools/modality_overview.py table` from the reports in `/home/ikohut/tmp/modality-overview-deployment`.
