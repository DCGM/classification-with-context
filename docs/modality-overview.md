# Modality overview: all models on every combination of main signals they can handle

Selected checkpoint (`finetune_best.pt`) of each run on the 193 full dev streams, without page numbers and without document boundaries; only the scan start and end are given. Each section is one combination of the main signals (S statistics, T text, I image): the other signals are masked as in the modality ablations (vectors and presence zero), and every model trained with at least these signals is listed. A model is named by its experiment, the signals it was trained with and its context window. Overlapping windows are merged as deployed in MetaKat, scaled to the window: overlap W/8 (64 at W512), regular tail, centre-weighted cubic logits with the ramp ending at 3/4 of the overlap and 3/16 of the overlap ignored at artificial window edges.

- **Page type**: the 3,758 curated dev pages. Precision, recall and F1 are support-weighted averages over the page types, as in the README's page type evaluation.
- **Side**: the 111,193 dev pages with a DB placement (left/right/single), weighted the same way.
- **Border**: the 1,786 true document starts; precision, recall and F1 of the predicted starts (threshold 0.5). Models without pairwise boundary prediction show none.
- **Both**: the same document starts predicted by the agreement of the page-start head (on the later page) and the page-end head (on the earlier page): a border only where both fire (threshold 0.5).

All values in %. Generated by `tools/modality_overview.py table` from the reports in `/home/ikohut/tmp/modality-overview-deployment`.

Every window trains on the same sampled data: the sampler draws 64 windows of 512 pages per update (complete scans tiled without overlap), and each is cut into consecutive pieces of W pages, so page pairs across a cut, about 1/W of them, boundaries included, are not trained. Fixed 16,000 pretraining and 4,000 fine-tuning updates without early stopping, input dropout seeded per update, the best checkpoint of each phase selected on dev. One seed per window. Evaluated as above, with all three signals; the merging overlap scales with W (W/8, at least one page). The W1 models of r21 (cut the same way, W1 sections above) complete the series.

## Borders from the page edge heads

The same evaluation of document starts, scored by different heads of the same models, on every adjacent page pair inside a scan (the scan start and end are never scored). **Pair**: the pairwise border head (as above). **Start**: the page-start head on the later page of each pair, i.e. the start head itself on every page but the first of the scan (is this page a document start?). **End**: the page-end head on the earlier page, i.e. the end head itself on every page but the last (is this page a document end?). **Both**: a border only where both fire (the smaller of the two probabilities at threshold 0.5). AP: average precision of the scores. The W1 model has no pairwise head; its page edge heads give it borders.
